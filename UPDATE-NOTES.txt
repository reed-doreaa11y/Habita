Habita v80 — Goal-first categories and safer planning

- Goal creation starts with the goal itself; category is suggested from its name and remains editable in the next step.
- Preserved the six standard categories and their existing IDs, icons, and colours. Unknown goals use Knowledge as a quiet editable suggestion rather than exposing an Uncategorised bucket for new goals. Legacy uncategorised goals remain preserved.
- Added the simple backup-path action when learning-path generation reports an error. The fallback is explicitly labelled as a starter path, not AI-generated curriculum.
- Removed the weekly cap that placed unrelated goals in a waiting state; goals stay active alongside each other.
- Kept existing app data, goals, habits, paths, and other files from the category-first v79 archive.

Validation: ZIP integrity and inline JavaScript syntax checked. Browser/device testing still required.

Habita v79 — Category-first goal creation

- Add a Goal now opens category selection first.
- Added Health, Career, Finance, Personal, Creativity, and Knowledge as standard categories while preserving existing category IDs and saved goals.
- Selecting a category advances to the existing goal-creation flow and carries the chosen category into the new goal.
- Removed the Add category button from the Goals list screen; category creation is available during category selection in the Add a Goal flow.
- Changed the Goals heading and empty-state prompt to “What do you want to achieve?”
- Existing goals, habits, learning paths, progress, and other project files are preserved from the complete v78 archive.

Validation: ZIP integrity checked and inline JavaScript syntax checked. Not yet device/browser-tested.
