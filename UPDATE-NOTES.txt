Habita v81.1 — Packaging and release-metadata correction

Based on the v81 awards, general schedule, and Friends build.

Packaging corrections:
- Removed the duplicate root-level main.js. index.html loads /src/main.js, which remains the single source of application JavaScript.
- Updated the package version to 0.81.1.
- Replaced stale v80-only release notes with notes for the contents of this archive.

Included features observed in the source:
- Awards UI and award-related logic.
- General schedule supports one-time commitments and weekly recurring commitments with selected weekdays.
- Almanac includes Journal, Calendar, Progress, and Friends. Friends is explicitly a preview; friend invitations and shared goal tracking are not active in this build.
- Goal-first categories and safer planning from v80 remain included.

Validation performed for this package:
- ZIP archive integrity checked.
- Confirmed index.html references /src/main.js and that no duplicate root main.js is shipped.
- JavaScript syntax check performed on the inline module source where supported.

Important limitations:
- This is not a claim of full browser/device or Firebase integration testing. Review the app in a browser and test persistence and user flows before treating it as production-ready.
- Existing user data is not included in the ZIP; the app's existing storage/cloud data should remain in its configured Firebase/browser storage when deploying the code update, but back up important data before replacing a deployed build.
